## 🎯 このシステムでできること

### 主な機能

このシステムは、**商品を自動的に箱に仕分けする**ためのツールです。以下のようなことができます：

#### 1. 📦 **商品の自動仕分け**
   - Excelに商品リストを入力するだけで、自動的に箱に分類
   - カテゴリ別（夏物、冬物など）に自動振り分け
   - 箱がいっぱいになったら自動で新しい箱を作成

#### 2. 📷 **バーコード読み取り**
   - USBバーコードリーダーやカメラで商品をスキャン
   - スキャンした商品をリアルタイムでExcelに登録
   - 商品番号を自動採番（001, 002, 003...）

#### 3. 🏷️ **商品の分類管理**
   - カテゴリ、サブカテゴリ、タグ、メモで細かく分類
   - 後から分類情報を編集可能
   - 検索やフィルタ機能

#### 4. 📊 **データの一元管理**
   - すべてのデータを1つのExcelファイルで管理
   - 自動集計機能
   - ダッシュボードで統計情報を確認

**必要なもの:**

```bash

```

### ステップ2: インストール

ターミナル（コマンドプロンプト）を開いて、プロジェクトフォルダに移動します：

## 🔧 各機能の詳しい使い方

### 機能1: 📦 バーコードスキャナー

**この機能でできること:**
- USBバーコードリーダーやカメラで商品をスキャン
- スキャンした商品を自動的にExcelに登録
- 商品番号を自動採番（001, 002, 003...）
- 箱への自動振り分け

**使い方:**

#### ステップ1: 機能を選択
メインメニューで「1」を入力してEnter

#### ステップ2: モードを選択
```
モードを選択してください:
1. USBバーコードリーダー (キーボード入力)
2. カメラでスキャン
3. 終了
```

**モード1: USBバーコードリーダー**
1. USBバーコードリーダーをPCに接続
2. 「1」を選択
3. 商品のバーコードをスキャン
4. 商品が見つかった場合 → 自動的に登録されます
5. 商品が見つからない場合 → 商品名を入力して登録
6. Enterキーを押すと終了

**モード2: カメラでスキャン**
1. 「2」を選択
2. カメラが起動します
3. 商品のバーコードをカメラに向ける
4. 自動認識されたら登録されます
5. 「q」キーを押すと終了

**実際の使用例:**
```
バーコードをスキャンしてください（終了するにはEnterを押してください）:
4901234567890

✅ 商品が見つかりました: T-shirt
📦 商品を登録しました:
   商品名: T-shirt
   商品番号: 001
   箱名: Summer-1A
   バーコード: 4901234567890
```

### 機能2: 📋 Excel一括処理

**この機能でできること:**
- Excelファイルにある商品リストを一括で読み込み
- 自動的に箱に分類
- 結果をExcelファイルに出力

**使い方:**

#### ステップ1: Excelファイルを準備

同じフォルダに `products.xlsx` という名前でExcelファイルを作成します。

**ファイルの形式:**
- A列の1行目に「商品名」と入力
- 2行目以降に商品名を入力

**例:**
| 商品名 |
|--------|
| T-shirt |
| T-shirt |
| Jacket |
| Socks |
| T-shirt |
| Scarf |
| Jacket |

#### ステップ2: 機能を実行

メインメニューで「2」を選択

#### ステップ3: 結果を確認

実行後、`商品管理マスター.xlsx` の「商品一覧」シートに結果が保存されます。

**出力結果の例:**
| 商品名 | 商品番号 | 箱名 | 登録日時 |
|--------|----------|------|----------|
| T-shirt | 001 | Summer-1A | 2024-01-15 10:30:00 |
| T-shirt | 002 | Summer-1A | 2024-01-15 10:30:01 |
| Jacket | 003 | Winter-1A | 2024-01-15 10:30:02 |
| Socks | 004 | 00-1A | 2024-01-15 10:30:03 |

**分類のルール:**
- 各商品は自動的にカテゴリに振り分けられます
- 同じカテゴリの商品は同じ箱に分類されます
- 1箱あたり5個まで入ります（設定で変更可能）
- 箱がいっぱいになると、新しい箱が自動で作られます

## ❓ よくある質問

### Q1: 箱の容量を変更したい

**A:** `auto_box_sorter.py` または `barcode_scanner.py` の `BOX_CAPACITY` を編集してください：

```python
BOX_CAPACITY = 10  # 1箱あたり10個まで（デフォルトは5）
```

### Q2: カテゴリの分類ルールを変更したい

**A:** `auto_box_sorter.py` または `barcode_scanner.py` の `CATEGORY_RULES` を編集してください：

```python
CATEGORY_RULES = {
    "T-shirt": "Summer",
    "Jacket": "Winter",
    "新しい商品名": "新しいカテゴリ名"
}
```

### Q3: バーコードをスキャンしても商品が見つからない

**A:** 以下の方法で解決できます：

1. プログラム実行時に商品名を入力すると、自動的にバーコードマスターに登録されます
2. 次回からは自動的に認識されます

### Q4: Excelファイルを直接編集しても大丈夫？

**A:** はい、`商品管理マスター.xlsx` をExcelで直接開いて編集できます。ただし、以下の点に注意してください：

- 「商品番号」列は重複しないようにしてください
- 「商品名」列は必ず入力してください
- 列の名前を変更しないでください

### Q5: データをバックアップしたい

**A:** `商品管理マスター.xlsx` ファイルをコピーして保存するだけでOKです。この1つのファイルにすべてのデータが入っています。

### Q6: 複数のPCで使いたい

**A:** プロジェクトフォルダ全体をUSBメモリなどにコピーして、別のPCに移動してください。ただし、Python環境が必要です。
