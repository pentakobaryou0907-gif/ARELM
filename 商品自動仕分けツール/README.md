
# 商品自動箱仕分けシステム

Excelにある製品リストを読み込んで、各商品を自動で「箱（Box）」に分類し、結果を新しいExcelファイルに出力するPythonプログラムです。

**🆕 バーコード読み取り機能追加！** バーコードをスキャンして自動的にExcelに商品データを追加できます。

**初心者の方や詳しい使い方が知りたい方は、まずこちらをご覧ください：**

👉 **[使い方ガイド.md](使い方ガイド.md)** - 完全な使用マニュアル、実践的な使用例、よくある質問が載っています

## ⚡ すぐに始める（3ステップ）

1. **インストール**: `./install.sh` を実行
2. **起動**: `python3 launcher.py` または `./start.sh` を実行
3. **使用**: メニューから機能を選択（1-6の数字を入力）

これだけです！すべての機能がメニューから利用できます。

## 📋 機能

### 基本機能
- ✅ Excelから商品リストを自動読み込み
- ✅ カテゴリ別に自動で箱に分類
- ✅ 箱がいっぱいになったら新しい箱を自動生成
- ✅ 商品番号を自動採番（001, 002, ...）
- ✅ 結果をExcelファイルに自動出力

### バーコード読み取り機能（新規）
- 📦 **USBバーコードリーダー対応** - バーコードをスキャンして自動登録
- 📷 **カメラでスキャン** - スマホやWebカメラでバーコードを読み取り
- 🔄 **リアルタイムExcel追加** - スキャンした商品を即座にExcelに追加
- 📚 **バーコードマスター管理** - バーコードと商品名のマッピングを管理

## 📖 使用方法

### 方法1: Excelファイルから一括処理

#### 1. 入力Excelファイルの準備

同じフォルダに `products.xlsx` を配置し、A列に「商品名」列を作成してください。

**例（products.xlsx）:**
| 商品名 |
|--------|
| T-shirt |
| T-shirt |
| Jacket |
| Socks |
| T-shirt |
| Scarf |
| Jacket |

#### 2. プログラムの実行

```bash
python auto_box_sorter.py
```

#### 3. 結果の確認

実行後、`sorted_products.xlsx` が自動生成されます。

**出力例:**
| 商品名 | 商品番号 | 箱名 |
|--------|----------|------|
| T-shirt | 001 | Summer-1A |
| T-shirt | 002 | Summer-1A |
| Jacket | 003 | Winter-1A |
| Socks | 004 | 00-1A |
| T-shirt | 005 | Summer-1A |
| Scarf | 006 | Winter-1A |
| Jacket | 007 | Winter-1B |

### 方法2: バーコードスキャナーでリアルタイム登録 🆕

#### 1. バーコードマスターの準備（初回のみ）

`barcode_master.xlsx` ファイルにバーコードと商品名のマッピングを登録します。

**barcode_master.xlsx の形式:**
| バーコード | 商品名 |
|-----------|--------|
| 4901234567890 | T-shirt |
| 4901234567891 | Jacket |
| 4901234567892 | Scarf |

または、プログラム実行時に初回スキャン時に自動登録することもできます。

#### 2. バーコードスキャナーの起動

```bash
python barcode_scanner.py
```

#### 3. モード選択

```
モードを選択してください:
1. USBバーコードリーダー (キーボード入力)
2. カメラでスキャン
3. 終了
```

**モード1: USBバーコードリーダー**
- USBバーコードリーダーをPCに接続
- バーコードをスキャンすると自動的にExcelに追加されます
- Enterキーを押すと終了

**モード2: カメラでスキャン**
- Webカメラまたはスマホのカメラを使用
- バーコードをカメラに向けると自動認識
- qキーを押すと終了

#### 4. 自動登録の流れ

1. バーコードをスキャン
2. バーコードマスターから商品名を検索
3. 商品が見つかった場合 → 自動的にExcelに追加
4. 商品が見つからない場合 → 商品名を入力して新規登録

**出力ファイル（sorted_products.xlsx）:**
| 商品名 | 商品番号 | 箱名 | バーコード | 登録日時 |
|--------|----------|------|-----------|----------|
| T-shirt | 001 | Summer-1A | 4901234567890 | 2024-01-15 10:30:00 |
| Jacket | 002 | Winter-1A | 4901234567891 | 2024-01-15 10:31:00 |

## ⚙️ カスタマイズ

### カテゴリルールの変更

`auto_box_sorter.py` の `CATEGORY_RULES` を編集してください：

```python
CATEGORY_RULES = {
    "T-shirt": "Summer",
    "Jacket": "Winter",
    "Scarf": "Winter",
    "Sunglasses": "Summer",
    "Socks": "00"
}
```

### 箱の容量変更

`BOX_CAPACITY` を変更してください：

```python
BOX_CAPACITY = 5  # 1箱あたりの最大数
```

### 未定義商品の処理

ルールに含まれていない商品は自動的に「00」箱に分類されます。

## 📊 統合Excelファイル（商品管理マスター.xlsx）

**すべてのデータを一つのExcelファイルで管理！** 見やすく整理された複数のシートで構成されています。

### シート構成

1. **商品一覧** - 仕分け済みの全商品データ
   - 商品名、商品番号、箱名、バーコード
   - **カテゴリ**、**サブカテゴリ**、**タグ**、**メモ**（細かい分類用）
   - 登録日時

2. **バーコードマスター** - バーコードと商品名のマッピング
   - バーコード、商品名、登録日時

3. **入力データ** - 元の商品リスト（参照用）
   - 商品名

4. **分類管理** - 商品分類のマスター（新規）
   - カテゴリ、説明、色コード

5. **集計・ダッシュボード** - 統計情報と集計
   - 登録商品総数、箱別商品数、商品別登録数
   - **カテゴリ別商品数**（新規）

### 統合Excelファイルの初期化

初回実行時に自動的に統合Excelファイルが作成され、既存のデータも自動移行されます：

```bash
python excel_manager.py
```

または、`barcode_scanner.py`や`auto_box_sorter.py`を実行すると自動的に統合ファイルが作成されます。

## 🏷️ 商品の細かい分類機能（新規）

### 分類項目

商品一覧シートに以下の列が追加されました：

- **カテゴリ** - 大分類（例: アパレル、食品、雑貨）
- **サブカテゴリ** - 中分類（例: トップス、ボトムス）
- **タグ** - 自由なタグ付け（例: 新商品、セール中、季節商品）
- **メモ** - 自由なメモ（例: 在庫注意、優先商品）

### 商品分類編集ツール

```bash
python product_editor.py
```

このツールで以下ができます：

1. **商品一覧を表示** - 分類情報を含む商品一覧を表示
2. **商品の分類情報を編集** - 商品番号を指定して分類情報を更新
3. **カテゴリでフィルタ** - カテゴリ別に商品を表示
4. **カテゴリ管理** - カテゴリのマスターを管理

### Excelで直接編集

`商品管理マスター.xlsx`の「商品一覧」シートを開いて、直接編集することもできます：

- カテゴリ列、サブカテゴリ列、タグ列、メモ列に直接入力
- Excelのフィルタ機能でカテゴリ別に絞り込み
- ソート機能で分類順に並び替え

## 💡 トラブルシューティング

### エラー: launcher.py が見つかりません
→ プロジェクトフォルダに移動してから実行してください。
→ または `python3 /完全なパス/launcher.py` を実行してください。

### エラー: Permission denied (start.sh や install.sh)
→ 実行権限を付与してください: `chmod +x start.sh install.sh`

### エラー: products.xlsx が見つかりません
→ 同じフォルダに `products.xlsx` を配置してください。

### エラー: Excelファイルに「商品名」列が見つかりません
→ ExcelファイルのA列に「商品名」という列名を設定してください。

### エラー: ModuleNotFoundError: No module named 'openpyxl'
→ `pip install -r requirements.txt` を実行してください。
→ または `./install.sh` を実行して自動インストールしてください。

### エラー: ModuleNotFoundError: No module named 'pyzbar'
→ カメラ機能を使用する場合: `pip install pyzbar opencv-python` を実行してください。
→ macOSの場合: `brew install zbar` も必要です。

### バーコードをスキャンしても商品が見つからない
→ `barcode_master.xlsx` にバーコードと商品名を登録してください。
→ または、プログラム実行時に商品名を入力すると自動的にマスターに追加されます。

### USBバーコードリーダーが動作しない
→ バーコードリーダーがHIDデバイス（キーボード入力）として認識されているか確認してください。
→ 多くのUSBバーコードリーダーは自動的にキーボード入力として動作します。
