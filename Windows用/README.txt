ARELM を Windows のデスクトップで使う

【はじめに（1回だけ）】
 1. このZIPを右クリック→「すべて展開」で展開する（展開しないと動きません）。
 2. 「ARELM-install.bat」をダブルクリックする。
    (「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」)
    ※ ZIPの中から直接実行せず、必ず展開したフォルダの中のものを実行する。
 3. デスクトップに「ARELM」のアイコンができる。

【使うとき】
 ・デスクトップの「ARELM」をダブルクリックする。
 ・はじめて開くときだけ、出てきた画面で「Macに許可を頼む」を押し、
   Mac の画面に出る知らせで「許可」を押す（合言葉もパスワードも要りません）。

【前提】
 ・Mac の電源が入っていて、ARELM が起動していること。
 ・この PC と Mac が、同じ Wi-Fi / 同じネットワークにいること。
 ・Mac の設定「他の端末から使う」がオンになっていること。
 ・Windows 10 (1803) 以降。

【できないこと・注意】
 ・Windows Hello（指紋・顔）でのログインは、いまは使えません。
   ブラウザの決まりで、https で開いたときだけ使えるためです。
   (Mac で Tailscale を設定すると、使えるようにできます)
 ・Mac のアドレスが変わったときは、ARELM-target.txt の2行目の番号を書き換えてください。
 ・外出先など、別のネットワークからは、Tailscale が必要です。

【やめたいとき】
 ARELM-uninstall.bat を実行する。Mac 側のデータは消えません。
