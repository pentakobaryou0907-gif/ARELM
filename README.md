# ARELM 社内専用作業ツール

過去のファッション制作情報をまとめ、**搭載AIと連携**する社内ハブです。  
（Base44型の **API Gateway** で公式APIのみ安全に利用）

## 起動方法

### Macの場合

1. **ダブルクリックで起動**
   - `AReGLMを開く.command` をダブルクリック
   - または `launch.sh` をダブルクリック
   - 自動的にサーバーとAIエンジンが起動し、ブラウザで開きます

2. **手動で起動する場合**
   ```bash
   cd /Users/ari/Developer/AReGLM/server
   npm install
   npm start
   ```

### Windowsの場合

1. **バッチファイルで起動**
   - `AReGLMを開く.bat` をダブルクリック

### アクセス方法

- **この端末から**: http://127.0.0.1:8090 または http://localhost:8090
- **同じWi-Fi内の他の端末から**: http://[MacのIPアドレス]:8090
  - 例: `http://192.168.1.5:8090`
  - MacのIPアドレスは、システム設定 → ネットワーク で確認できます

**ログイン**: `admin` / `Admin@2024!`

**重要**: ポート **8090** でアプリを開き、ポート **8080** が内部APIサーバーです。

1. **AIチャット** — ChatGPT風1画面（会話・分析・学習・制作・画像・モック・TP）
2. **ブランドハブ** — ロゴ・国・ジャンル・AI調査
3. **SNS** — [@areglm](https://www.instagram.com/areglm/) 等4公式アカウント連携
4. **在庫・売上** — [suzuri.jp/areglm](https://suzuri.jp/areglm) の商品のみ
5. **商品開発** — SUZURI公式APIでグッズ作成 → 在庫へ同期

## 他の端末から使う（複数デバイス対応）

ARELMは、スマホ・タブレット・他のPCからも安全にアクセスできます。

### 📱 設定手順

#### 1. Mac側（サーバー）での設定

1. ARELMを開く
2. 設定（⚙）→「他の端末から使う」を開く
3. 使いたい方法を選んで設定:

   **方法A: 同じWi-Fi内のみ（シンプル）**
   - 「他の端末から使う」を**オン**
   - 「合言葉」を設定（8文字以上）
   - 保存

   **方法B: Tailscale VPN（外出先からも安全にアクセス）**
   - 先に [TAILSCALE_SETUP.md](./TAILSCALE_SETUP.md) を参照してTailscaleをセットアップ
   - 「Tailscaleから使う」を**オン**
   - 「合言葉」を設定（8文字以上）
   - 保存

4. MacのIPアドレスを確認:
   - 同じWi-Fiの場合: システム設定 → ネットワーク → 「192.168.x.x」など
   - Tailscaleの場合: メニューバーのTailscaleアイコン → 「100.x.x.x」

#### 2. スマホ・タブレット（iPhone/iPad/Android）からアクセス

1. Safariまたは Chrome を開く
2. アドレスバーに入力:
   ```
   http://[MacのIPアドレス]:8090
   ```
   例:
   - 同じWi-Fi: `http://192.168.1.5:8090`
   - Tailscale: `http://100.64.1.5:8090`

3. 初回アクセス時:
   - 合言葉の入力画面が表示されます
   - Mac側で設定した合言葉を入力
   - 端末の名前（例: 「iPhone」）を入力
   - 「入る」をタップ

4. **ホーム画面に追加（PWAインストール）**:
   
   **iPhone/iPadの場合:**
   - Safariの画面下部の「共有」ボタン（□に↑）をタップ
   - 「ホーム画面に追加」を選択
   - 名前は「ARELM」のままでOK
   - 「追加」をタップ
   
   **Androidの場合:**
   - Chromeの右上のメニュー（⋮）をタップ
   - 「ホーム画面に追加」を選択
   - 「追加」をタップ

   これでホーム画面にARELMのアイコンが追加され、アプリのように使えます！

#### 3. 他のPC（Windows/Mac）からアクセス

1. ブラウザ（Chrome推奨）で以下を開く:
   ```
   http://[MacのIPアドレス]:8090
   ```

2. 合言葉を入力して「入る」

3. 通常通り使用できます

### 🔒 セキュリティについて

- **合言葉**: 8文字以上、他では使っていない強力なものを設定してください
- **認証**: 初回アクセス時のみ合言葉が必要。その後30日間は記憶されます
- **外部からの遮断**: 
  - 同じWi-Fi: 家庭内ネットワーク（192.168.x.x等）のみ許可
  - Tailscale: あなたが承認した端末のみ接続可能
  - それ以外: 完全に遮断されます

### ⚠️ 制限事項

- **マイク機能**: HTTP接続ではブラウザのセキュリティ上、マイクは使えません
  - マイクを使いたい場合は HTTPS化が必要です（[TAILSCALE_SETUP.md](./TAILSCALE_SETUP.md) の「HTTPS化」を参照）
- **Mac側の起動**: Mac側でARELMサーバーが起動している必要があります
- **ネットワーク**: 同じWi-FiまたはTailscaleに接続している必要があります

### 🛠 トラブルシューティング

**「合言葉が違います」と表示される**
- 入力した合言葉が間違っている
- Mac側で合言葉を再設定してみてください

**接続できない**
1. Mac側でARELMが起動しているか確認
2. 同じWi-Fi / Tailscaleに接続しているか確認
3. IPアドレスが正しいか確認
4. Mac側の設定で「他の端末から使う」または「Tailscaleから使う」がオンになっているか確認

**アクセスは拒否されました**
- Mac側の設定で該当する接続方法がオンになっていない可能性があります
- 設定（⚙）→「他の端末から使う」を確認してください

詳しくは [TAILSCALE_SETUP.md](./TAILSCALE_SETUP.md) を参照してください。
