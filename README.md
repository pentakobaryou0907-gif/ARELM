# ARELM 社内専用作業ツール

過去のファッション制作情報をまとめ、**搭載AIと連携**する社内ハブです。  
（Base44型の **API Gateway** で公式APIのみ安全に利用）

利用者は本人1人。Mac を本体にし、同じWi-Fiの他の端末、または Tailscale（閉じた回線）から開けます。インターネットへ公開する設定は使いません。

## 起動方法

### Mac（本体）

1. **ダブルクリックで起動**
   - `AReGLMを開く.command` をダブルクリック
   - または `launch.sh` をダブルクリック
   - サーバーとAIエンジンが起動し、ブラウザで開きます

2. **このMacから開くアドレス**
   - **http://127.0.0.1:8090**（こちらが本体の入口）
   - `8080` は Cursor など別のアプリが先に持つことがあり、古い画面に当たることがあります

ログイン: `admin` / `Admin@2024!`

## 登録するAPIキー（すべて公式・無料）

| 種類 | 取得先 |
|------|--------|
| **Gemini**（必須） | https://aistudio.google.com/apikey |
| **Groq**（任意） | https://console.groq.com/keys |
| **Hugging Face**（画像・任意） | https://huggingface.co/settings/tokens |
| **SUZURI**（在庫・開発） | https://suzuri.jp/developer |
| **Instagram / Facebook / TikTok / YouTube** | 各公式開発者コンソール |
| **Google Client ID**（写真・任意） | Google Cloud Console |

設定（⚙）で入力 → **暗号化保存**。劣るAPIは自動除外。

## 4つの機能 + 商品開発

1. **AIチャット** — ChatGPT風1画面（会話・分析・学習・制作・画像・モック・TP）
2. **ブランドハブ** — ロゴ・国・ジャンル・AI調査
3. **SNS** — [@areglm](https://www.instagram.com/areglm/) 等4公式アカウント連携
4. **在庫・売上** — [suzuri.jp/areglm](https://suzuri.jp/areglm) の商品のみ
5. **商品開発** — SUZURI公式APIでグッズ作成 → 在庫へ同期

## 販売先

**SUZURIのみ:** https://suzuri.jp/areglm（他ECは使用しません）

## セキュリティ

- 犯罪・違法コンテンツは拒否
- APIキーはブラウザ内暗号化 + Gateway経由で外部送信
- 非公式APIは不使用
- 他の端末は合言葉が通るまで、画面もデータも渡しません
- インターネットへの公開（Tailscale Funnel など）は使いません

## 全自動モード

ホームの「全自動」ON + ヘッダー「↻」で SUZURI同期 · SNS宣伝 · AIニュース を実行

## 他の端末から使う（端末ごとの手順）

他の端末で開くには、**合言葉**と、いつもの**ユーザー名・パスワード**の両方が要ります。  
合言葉は画面に出ません。Mac の設定で、ご自身が決めます（開発側が決めません）。

設定の場所:

- **同じWi-Fi** … 設定（⚙）→「他の端末から使う」
- **外出先・別の回線** … 設定（⚙）→ 三端末の「どこでも」（Tailscale）
- アドレスのコピーとQRも、同じ設定画面にあります

詳しい Tailscale の手順は [TAILSCALE_SETUP.md](./TAILSCALE_SETUP.md) を見てください。

### 1. Mac（本体）で先にすること

1. ARELM を起動する（上の「起動方法」）
2. **同じWi-Fiだけ**使うとき:
   - 設定 →「他の端末から使う」を開く
   - 合言葉を決める（8文字以上。他では使っていないもの）
   - 「他の端末から使えるようにする」を押す
   - 画面に出るアドレス（例: `http://192.168.x.x:8080`）を控える  
     ※ 同じWi-Fiの入口は、画面に出た番号を使ってください。8090 は Mac の中だけの入口です
3. **外出先からも**使うとき:
   - 設定 → 三端末 →「どこでも」を開く
   - Tailscale が入っていなければ、Mac のターミナルで `brew install tailscale`
   - 「どこでも使えるようにする」を押し、本人のアカウントでログインする（ログイン情報は本人が入れる）
   - 画面に出る `https://….ts.net` を控える
4. Mac は起動したまま、ARELM も動かしたままにしておく

### 2. iPhone / iPad

1. **外出先**なら、先に App Store で Tailscale を入れ、Mac と同じアカウントでログインする
2. Safari で、Mac の画面に出たアドレスを開く
   - 同じWi-Fi: `http://[画面に出たLANの住所]`
   - 外出先: `https://[画面に出た ts.net の住所]`
3. 合言葉 → 端末の名前 →「入る」
4. いつものユーザー名とパスワードでログインする
5. **ホーム画面に追加（アプリのように使う）**
   - Safari 下部の「共有」（□に↑）→「ホーム画面に追加」→ 名前は「ARELM」→「追加」
   - iPad は、設定の「iPad用のアイコン（プロファイル）」からも入れられます

### 3. Android

1. 外出先なら Tailscale アプリを入れ、同じアカウントでログインする
2. Chrome で、Mac の画面に出たアドレスを開く
3. 合言葉とログインを済ませる
4. Chrome 右上「⋮」→「ホーム画面に追加」

### 4. 他の PC（Windows / 別の Mac）

1. 外出先なら Tailscale を入れ、同じアカウントでログインする（[tailscale.com/download](https://tailscale.com/download)）
2. ブラウザ（Chrome 推奨）で、Mac の画面に出たアドレスを開く
3. 合言葉とログインを済ませる
4. Windows は、設定の「Windows用のアプリ（ZIP）」→ `ARELM-install.bat` でもデスクトップにアイコンを置けます

### 守り

- 合言葉は 8文字以上。他のサービスで使っている言葉は使わない
- 初回だけ合言葉を聞く。その後 30日は、その端末では聞かない
- 同じWi-Fi: 家庭内の住所だけ通す。合言葉が通るまで中身は渡さない
- Tailscale: 本人が承認した端末だけ。インターネットには出さない（Funnel は使わない）
- 端末の許可・パスワードの決め直しは、Mac 本体の画面からだけ

### 制限

- **マイク**: 他の端末の http では使えません。https（「どこでも」の Tailscale アドレス）なら使えます
- Mac がスリープ・電源オフだと、他の端末からは開けません
- SUZURI の「商品を公開する」は、本人が押します

### うまくいかないとき

| 表示 | 見ること |
|------|----------|
| 合言葉が違います | Mac の設定で合言葉を決め直す（中身は画面に出ません） |
| 接続できない | Mac で ARELM が動いているか／同じWi-Fiか Tailscale か／画面に出たアドレスか |
| アクセスは拒否されました | 「他の端末から使う」または「どこでも」がオンか |
| 古い画面・マイクが使えない | Mac では 8090 で開く。他の端末では https（どこでも） |

Mac が無いときの公開先（GitHub Pages）は、このMac本体とは別の入口です。同期と会話の形は設定画面と `AGENTS.md` を見てください。
