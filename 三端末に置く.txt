AReGLM を Mac / Windows / iPad の三端末で使う

いま開いている「AIツール開発プロジェクト\README.md」はメモ用です。アプリではありません。

────────────────────────────────
共通の考え方
────────────────────────────────
・本体のサーバーは「Mac」か「Windows」のどちらか（または両方）で動かします。
・iPad はサーバーを持てないので、Safari から Mac/Windows の入口を開き、
  「ホーム画面に追加」でアプリのようにします。
・三端末で同じデータを使うなら、Mac を親にして Tailscale を入にするのが安全です
  （同じ Wi‑Fi に入口を晒さずに、自分の端末だけつなぎます）。

────────────────────────────────
1. Mac（ホーム画面に AReGLM.app）
────────────────────────────────
1) このリポジトリ（ツール本体）を Mac に置く
2) 「三端末に置く.command」をダブルクリック
   （または「ホーム画面に置く.command」だけでも可）
3) デスクトップ / アプリケーション の AReGLM.app を開く
4) 設定 → 他の端末 → 合言葉を決めて
   「Tailscaleから使えるようにする」を入にする
5) Tailscale アプリを Mac に入れ、ログインしておく

────────────────────────────────
2. Windows（デスクトップに AReGLM を出す）
────────────────────────────────
いま README.md（メモ）しか見えないとき:

A) Git がある場合 — PowerShell にそのまま貼る:

$dest = "$env:USERPROFILE\OneDrive\デスクトップ\AReGLM\ツール本体"
git clone --branch cursor/three-devices-home-1936 --single-branch https://github.com/pentakobaryou0907-gif/ARELM.git $dest
& "$dest\デスクトップにAReGLMを出す.bat"

B) ZIP の場合:
1) https://github.com/pentakobaryou0907-gif/ARELM/tree/cursor/three-devices-home-1936
   緑の Code → Download ZIP
2) 解凍した中身を OneDrive\デスクトップ\AReGLM\ツール本体 へ
3) 「デスクトップにAReGLMを出す.bat」を開く
   （または「メモフォルダからデスクトップへ.bat」を
    AIツール開発プロジェクト の中にコピーして開く）

できたらデスクトップに「AReGLM」アイコンが出ます。
（iPad と共有するなら Tailscale を Windows にも入れる）

────────────────────────────────
3. iPad（ホーム画面に ARELM）
────────────────────────────────
1) Tailscale を入れ、Mac と同じアカウントでログイン
2) Mac 側で Tailscale 経由を入にしておく（上の手順）
3) Safari で Mac の画面に出た URL を開く
   例: https://100.x.x.x:8443
   （初回は証明書の警告 →「詳細」→「訪問を続行」）
4) 合言葉を入れる
5) 共有ボタン →「ホーム画面に追加」→ 追加
6) ホーム画面の ARELM アイコンから開く

────────────────────────────────
うまくいかないとき
────────────────────────────────
・iPad で開けない → Mac の AReGLM が起動しているか、Tailscale がつながっているか
・合言葉を忘れた → Mac の設定「他の端末」で合言葉を決め直す
・メモの README しか見えない → 「ツール本体」フォルダを開いているか確認
